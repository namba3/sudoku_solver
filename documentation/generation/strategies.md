# FastとDiverse

[問題生成資料](../generation.md)へ戻る。

## Fast

`generator::generate_puzzle_with_clues(seed, clue_count)`は、目標以下のヒント数にある検証済みMinimal盤面をまとめたプールから1件をseedで選び、盤面と解に同じランダム対称変換を100回連続で適用します。目標数に足りない分だけ、その解から数字を追加します。たとえば18ヒント生成ではMinimal 17・18、19ヒント生成ではMinimal 17〜19が選択対象です。該当するヒント数の組み込み盤面がまだない場合は、存在する少ないヒント数の盤面から補います。選択確率はヒント数ごとではなく、プール内の各盤面で均等です。同じseedとヒント数なら同じ盤面を返します。

基準盤面は[`MINIMAL_PUZZLES_BY_CLUE_COUNT`](../../src/minimal_puzzle_seeds.rs)に、添字がヒント数となる配列で保持しています。現在の組み込み数は17ヒント7組、18ヒント135組、19ヒント668組、20ヒント600組です。Archiveへ登録した問題と、生成器に組み込んだseedは別管理です。追加したseedを配列へ反映する手順は[Archive資料](archive.md)を参照してください。

## Diverse

`generator::generate_diverse(seed, clue_count, budget)`は、既知の17ヒント盤面を起点に、同値類が異なる一意解盤面を探索します。`DiverseStrategy`で探索方式を選び、有限の候補・ノード予算を超えた場合はエラーを返します。

| 方式 | 概要 |
| --- | --- |
| `adaptive` | 18ヒント経由と設定範囲の中間状態を試し、次に`-2+2`、`-1+1`、`-3+3`を探索する既定方式 |
| `swap-1+1`, `swap+1-1` | 1ヒント交換。`+1-1`は合法候補外の数字も検査する |
| `swap-2+2`, `swap-3+3` | 2個または3個を交換する |
| `via-18`, `via-intermediate` | 18ヒント、または設定した中間ヒント数を経由する |
| `drift-walk` | 1ヒントずつ増減する独立したランダムウォーク |
| `random-17-witness` | ランダム完成盤面と17セルから始め、別解のWitnessを探索に使う |
| `solution-space-pivot` | 16ヒント核へ候補を足し、一意性を直接調べる |

探索方式ごとの手順と枝刈りは[Diverse探索の詳細](diverse-details.md)、Pivotは[Pivot資料](pivot.md)、CLIの起動・再開方法は[CLIガイド](cli.md)を参照してください。

## 18〜81ヒント

17ヒント探索とは別の経路を使います。ランダム化した制約探索で完成盤面を作り、seedで決まる順にヒントを削除します。削除で別解が見つかったときは既知解との差分をunavoidable setとして記録します。目標数より多くヒントが残った場合、これらの制約を満たす目標サイズの部分集合をbounded hitting-set探索で組み立て、候補を再度一意性検査します。新しい別解が見つかれば制約を追加して探索します。

一意性検査とhitting-set探索には別々の有限予算があります。いずれも上限で結論が出なければ成功扱いせず、指定ヒント数まで届かない場合は`BudgetExhausted`になります。近いヒント数の盤面は返しません。

Web UIはFastのみを使います。Diverseと収集用CLIはWeb画面には表示されません。
