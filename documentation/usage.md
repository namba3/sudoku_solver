# 使い方と盤面形式

## ブラウザーで使う

アプリは[GitHub Pages](https://namba3.github.io/sudoku_solver/)で公開されています。

画面右上の言語切替ボタンで日本語と英語を切り替えられます。初期表示は日本語です。

- 9×9のセルへ数字を入力します。
- 矢印キーで隣のセルへ移動します。数字キーを押すと現在のセルの値を置き換え、次の空欄へ自動で移動します。
- 読み込んだ問題の数字は濃い青の背景と太字、内側の枠線で表示します。そのセルを編集すると自分の入力として扱います。
- 同じ行・列・3×3ブロックで数字が重複すると、該当セルを赤く表示します。
- **Show candidates**で空欄に置ける数字をセル内に表示し、**Hide candidates**で隠します。候補数字は1〜9の順に3×3で並びます。候補表示中はフォーカス中のセルでも候補を表示し、背景色で選択状態を示します。キャレットを隠して枠線を点滅させます（動きを抑える設定では点滅しません）。
- 候補がひとつもない空欄は赤く強調し、メッセージにも個数を表示します。
- ブラウザー画面のヒント操作は一時的に非表示です。Rust APIの`find_hint`は引き続き利用できます。
- **Clues / 初期数字数**に17〜81を指定し、**Generate puzzle / 問題を生成**で指定数の初期数字を持つ一意解のランダム問題を作成します。生成操作ごとに新しいseedを使います。初期値は30です。17未満では一意解の数独を作れないことが網羅計算で示されています（[McGuire et al., 2013](https://arxiv.org/abs/1201.0749)）。生成処理はバックグラウンドで動き、進行中は**Cancel generation / 生成を中断**で停止できます。生成した問題は初期数字として設定され、Undoで元の盤面へ戻せます。難易度の分類は行いません。
- **Solve**で解きます。成功すると解答と処理時間が表示されます。
- **Count solutions**で現在の盤面の解数を調べます。解を最大100件、探索ノードを約500,000件まで調べ、進捗・所要秒数・見つかった解・終了理由を表示します。ノード上限は進捗イベント間隔により最大2,047ノード超過する場合があります。探索中は**Cancel search**で中断できます。
- 探索が完了した場合は解数と所要秒数を表示します。100件の上限に達した場合は「100件以上」、ノード上限で止まった場合は「解数不明」と区別します。見つかった盤面は左右ボタンまたはスライダーで切り替えてプレビューできます。元の問題ですでに埋まっていた数字は青く強調します。**Use selected solution**で適用でき、適用後も一覧とプレビューは残ります。
- **Reset / リセット**で入力した数字を消し、初期数字の盤面へ戻します。戻した操作はUndoで取り消せます。
- **Clear**で初期数字も含めて盤面を空にします。
- **Undo / Redo**で数字の入力、問題の読み込み、Solve、Reset、Clearを最大100段階まで戻したりやり直したりできます。初期ヒントの状態も一緒に復元します。テキスト欄の編集と候補表示の切り替えは盤面履歴に含みません。
- セルにフォーカスがあるときは、**Ctrl/Cmd+Z**でUndo、**Ctrl/Cmd+Y**または**Ctrl/Cmd+Shift+Z**でRedoできます。
- **Save text ↓**で盤面をテキスト欄へ出力します。
- 「問題のテキスト」見出し横のコピーアイコンで、テキスト欄の内容をクリップボードへコピーできます。
- **↑ Load text**でテキスト欄の内容を盤面へ読み込みます。

重複する数字がある問題、または解が見つからない問題では失敗メッセージを表示します。画面は失敗理由を区別しません。

## テキスト形式

1行を盤面の1行として扱う、9行・各行9文字の形式です。数字`1`〜`9`をヒントとして読み込み、`0`、`.`、`_`を空欄として扱います。行数や各行の長さが合わない場合、またはそれ以外の文字がある場合は読み込みを中止し、位置を含むエラーを表示します。末尾の改行は付けても構いません。

```text
53__7____
6__195___
_98____6_
8___6___3
4__8_3__1
7___2___6
_6____28_
___419__5
____8__79
```

読み込み結果は盤面に反映されます。行・列・3×3ブロック内の重複がある場合も読み込みますが、該当セルを赤く表示して修正を促します。出力形式では空欄が`_`になります。

[`sample_problem/`](../sample_problem/)にも問題例があります。テキスト欄から読み込むときは、ファイルの中身を貼り付けてください。

## Rustライブラリとして使う

盤面型は`Matrix = [[u8; 9]; 9]`です。空欄に`0`を使います。`solve`は盤面を変更し、解けたかどうかを`bool`で返します。空欄セルの候補は`candidates_for(&board, x, y)`で取得できます（`x`は列、`y`は行）。埋まったセルや盤面外の座標では空の候補リストを返します。

```rust
use sudoku_solver::{solve, Matrix};

let mut board: Matrix = [
    [5, 3, 0, 0, 7, 0, 0, 0, 0],
    [6, 0, 0, 1, 9, 5, 0, 0, 0],
    [0, 9, 8, 0, 0, 0, 0, 6, 0],
    [8, 0, 0, 0, 6, 0, 0, 0, 3],
    [4, 0, 0, 8, 0, 3, 0, 0, 1],
    [7, 0, 0, 0, 2, 0, 0, 0, 6],
    [0, 6, 0, 0, 0, 0, 2, 8, 0],
    [0, 0, 0, 4, 1, 9, 0, 0, 5],
    [0, 0, 0, 0, 8, 0, 0, 7, 9],
];

if solve(&mut board) {
    println!("{board:?}");
}
```

`1`〜`9`以外の値は`solve`内で空欄として扱います。盤面に同じ数字が初期状態から重複している場合は`false`です。探索で最初に見つかった解を返し、解の一意性は検査しません。
