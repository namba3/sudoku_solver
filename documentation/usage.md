# 使い方と盤面形式

## ブラウザーで使う

アプリは[GitHub Pages](https://namba3.github.io/sudoku_solver/)で公開されています。

画面右上のボタンで表示言語を切り替え、月／太陽アイコンのスイッチでテーマを切り替えられます。初期表示は日本語・ダークテーマです。テーマの選択はこのブラウザーに保存され、次回も引き継がれます。

- 9×9のセルへ半角数字`1`〜`9`を入力します。数字以外のキーは無視され、貼り付けなどから届いた不正な値も盤面には入りません。
- 矢印キーで隣のセルへ移動します。数字キーを押すと現在のセルの値を置き換え、次の空欄へ自動で移動します。
- 盤面ツールバーに、現在の盤面に残っている空セルの数を表示します。
- 初期数字はデフォルトでロックされ、濃い青の背景と太字、内側の枠線で表示されます。**Unlock given numbers / 初期数字のロックを解除**で編集可能になり、編集した数字は通常の入力として扱われます。再ロック後も編集済みの数字はロックされません。
- **対称変換**パネルでは、band（横3行）・stack（縦3列）単位の交換、同じband/stack内での行・列交換、数字の交換を指定できます。転置、90°・180°・270°回転、上下・左右反転も選べます。変換は盤面と初期数字に同じように適用され、Undo/Redoで戻せます。交換対象の初期値は異なる番号が選ばれています。
- 盤面の左端にband番号と、その内側にbandごとの行番号を表示します。band番号はband全体を交換し、行番号は同じband内だけで行を交換します。上端のstack番号とstackごとの列番号も同じ関係です。各番号はドラッグするか、2つ選んで交換できます。交換可能な番号にドラッグすると入れ替わった盤面をプレビューし、対象範囲を強調します。操作はUndo/Redoに記録されます。
- 同じ行・列・3×3ブロックで数字が重複すると、該当セルを赤く表示します。
- 右パネル「ヒント」タブの**候補を表示 / Show candidates**スイッチをONにすると、空欄に置ける数字をセル内に表示します。候補数字は1〜9の順に3×3で並びます。候補表示中はフォーカス中のセルでも候補を表示し、背景色で選択状態を示します。キャレットを隠して枠線を点滅させます（動きを抑える設定では点滅しません）。
- ヒントタブの候補フィルターには全フィルターを一括ON/OFFするスイッチがあります。個別フィルターが1つ以上ONならスイッチもON表示となり、押すとすべてOFFになります。すべてOFFの状態で押すとすべてONになります。個別フィルターは引き続き個別に切り替えられます。Locked Candidates、Naked / Hidden Subsets、Fish、XY-Wing、Skyscraper、2-String Kite、W-Wingを選択した反復回数だけ適用します。回数の初期値は1回で、1〜100回を指定できます。1回の中では全手法が同じ候補状態をもとに除外候補を探し、見つかった除外をまとめて反映します。候補が変わらなくなった場合は指定回数に達する前に終了します。FishはX-Wing・Swordfish・Jellyfish（2〜4行／列）、Naked / Hidden SubsetsはPair・Triple・Quadを扱います。候補表示中は除外された数字に取り消し線を表示します。「Singleの強調」セクションの**候補フィルターを考慮**スイッチがONなら、Naked / Hidden Singleをフィルター後の候補から判定します。OFFならフィルター前の候補で判定します。
- 候補がひとつもない空欄は赤く強調し、メッセージにも個数を表示します。
- 初期表示の右パネル「ヒント」タブでは、**Naked Singleを強調**と**Hidden Singleを強調**を個別に切り替えられます。Naked Singleはセル自身の候補が1つだけの状態、Hidden Singleは行・列・ブロック内である数字の置き場所が1セルだけの状態です。該当セルを強調表示します。Rust APIの`find_hint`も両方の手法に対応します。
- 右パネルの**問題生成 / Generate**タブで初期数字数17〜81を指定して**Generate puzzle / 問題を生成**を実行します。入力欄の初期値は25です。Web UIはFast方式のみを使い、目標以下のヒント数を持つ既知の一意解初期盤面から1つ選び、盤面と解に同じランダム対称変換を100回適用します。その後、足りない数字を追加して一意解問題を生成します。各生成操作は新しいseedを使います。生成中は同じボタンが**Cancel generation / 生成を中断**に切り替わり、ヒント数の入力は固定されます。生成した問題は初期数字として設定され、Undoで元の盤面へ戻せます。難易度の分類は行いません。Diverse探索はCLI専用です。

17未満の初期数字で一意解の数独を作れないことは網羅計算で示されています（[McGuire et al., 2013](https://arxiv.org/abs/1201.0749)）。Diverse CLIの使い方は[問題生成資料](generation.md)からテーマ別資料を参照してください。
- **盤面を直接解く / Solve current board**で現在の盤面を解き、解答を盤面へ反映します。成功すると処理時間がページ上部に表示されます。
- 初期数字セルの右上には、ロック中は閉じた錠前、解除中は開いた錠前のアイコンが薄く表示されます。
- 初期数字のロックを解除すると、盤面ツールバー下の案内に従い、数字が入ったセルにフォーカスして**G**キーを押すことで初期数字と通常入力を切り替えられます。空セルでは何も起きず、切り替えはUndo/Redoできます。
- **Count solutions**で現在の盤面の解数を調べます。解を最大100件、探索ノードを約500,000件まで調べ、「解く・確認」パネル内に進捗・所要秒数・見つかった解・終了理由を表示します。ノード上限は進捗イベント間隔により最大2,047ノード超過する場合があります。探索中は同じボタンが**Cancel search / 探索を中断**に切り替わります。
- 盤面右側のタブから「ヒント」「問題生成」「解く・確認」「対称変換」「テキスト」を切り替えます。初期表示は「ヒント」です。
- 探索が完了した場合は解数と所要秒数を表示します。100件の上限に達した場合は「100件以上」、ノード上限で止まった場合は「解数不明」と区別します。見つかった盤面は左右ボタンまたはスライダーで切り替えてプレビューできます。元の問題ですでに埋まっていた数字は青く強調します。**Use selected solution**で適用でき、適用後も一覧とプレビューは残ります。
- **Restore initial board / 初期盤面に戻す**で入力した数字を消し、初期数字の盤面へ戻します。戻した操作はUndoで取り消せます。
- **Clear**で初期数字も含めて盤面を空にします。
- 盤面上部のボタン列から、**Undo / Redo**、候補表示、初期数字のロック、初期盤面への復元、クリアを操作できます。Undo / Redoでは数字の入力、問題の読み込み、Solve、初期盤面への復元、Clearを最大100段階まで戻したりやり直したりできます。初期ヒントの状態も一緒に復元します。テキスト欄の編集と候補表示の切り替えは盤面履歴に含みません。
- セルにフォーカスがあるときは、**Ctrl/Cmd+Z**でUndo、**Ctrl/Cmd+Y**または**Ctrl/Cmd+Shift+Z**でRedoできます。
- 「テキスト」パネル内の**盤面をテキストへ出力**で現在の盤面を欄へ出力します。
- **テキストから盤面へ読み込む**で欄の内容を盤面へ読み込みます。
- 「問題のテキスト」ラベル横のコピーアイコンで、欄の内容をクリップボードへコピーできます。

重複する数字がある問題、または解が見つからない問題では失敗メッセージを表示します。画面は失敗理由を区別しません。

## テキスト形式

改行を除いた81文字を盤面として読み込み、9文字ごとに行を区切ります。数字`1`〜`9`をヒントとして、`0`、`.`、`_`を空欄として扱います。9行に分けた形式と、81文字を続けた形式の両方を使えます。改行以外の空白や未対応の文字が含まれる場合は読み込みを中止し、盤面上の位置を表示します。

```text
53__7____
6__195___
_98____6_
8___6___3
4__8_3__1
7___2___6
_6____28_
___419__5
____8__79
```

読み込み結果は盤面に反映されます。行・列・3×3ブロック内の重複がある場合も読み込みますが、該当セルを赤く表示して修正を促します。出力形式では空欄が`_`になります。

[`sample_problem/`](../sample_problem/)にも問題例があります。テキスト欄から読み込むときはファイルの中身を貼り付け、CLIで分析するときは`analyze --file sample_problem/a.txt`のように指定できます。

## Rustライブラリとして使う

盤面型は`Matrix = [[u8; 9]; 9]`です。空欄に`0`を使います。`solve`は盤面を変更し、解けたかどうかを`bool`で返します。空欄セルの候補は`candidates_for(&board, x, y)`で取得できます（`x`は列、`y`は行）。埋まったセルや盤面外の座標では空の候補リストを返します。

```rust
use sudoku_solver::{solve, Matrix};

let mut board: Matrix = [
    [5, 3, 0, 0, 7, 0, 0, 0, 0],
    [6, 0, 0, 1, 9, 5, 0, 0, 0],
    [0, 9, 8, 0, 0, 0, 0, 6, 0],
    [8, 0, 0, 0, 6, 0, 0, 0, 3],
    [4, 0, 0, 8, 0, 3, 0, 0, 1],
    [7, 0, 0, 0, 2, 0, 0, 0, 6],
    [0, 6, 0, 0, 0, 0, 2, 8, 0],
    [0, 0, 0, 4, 1, 9, 0, 0, 5],
    [0, 0, 0, 0, 8, 0, 0, 7, 9],
];

if solve(&mut board) {
    println!("{board:?}");
}
```

`1`〜`9`以外の値は`solve`内で空欄として扱います。盤面に同じ数字が初期状態から重複している場合は`false`です。探索で最初に見つかった解を返し、解の一意性は検査しません。
