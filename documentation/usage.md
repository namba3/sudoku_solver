# 使い方と盤面形式

## ブラウザーで使う

アプリは[GitHub Pages](https://namba3.github.io/sudoku_solver/)で公開されています。

- 9×9のセルへ数字を入力します。
- **Solve**で解きます。成功すると解答と処理時間が表示されます。
- **Clear**で盤面を空にします。
- **Save text ↓**で盤面をテキスト欄へ出力します。
- **↑ Load text**でテキスト欄の内容を盤面へ読み込みます。

重複する数字がある問題、または解が見つからない問題では失敗メッセージを表示します。画面は失敗理由を区別しません。

## テキスト形式

1行を盤面の1行として扱う、最大9行・各行最大9文字の形式です。数字`1`〜`9`をヒントとして読み込み、数字以外の文字は空欄にします。行や文字が足りない部分は空欄です。余分な行・文字は読み込みません。

```text
53__7____
6__195___
_98____6_
8___6___3
4__8_3__1
7___2___6
_6____28_
___419__5
____8__79
```

空欄には`.`、`_`、スペースなどを使えます。読み込み結果は盤面に反映されます。出力形式では空欄が`_`になります。

[`sample_problem/`](../sample_problem/)にも問題例があります。テキスト欄から読み込むときは、ファイルの中身を貼り付けてください。

## Rustライブラリとして使う

盤面型は`Matrix = [[u8; 9]; 9]`です。空欄に`0`を使います。`solve`は盤面を変更し、解けたかどうかを`bool`で返します。

```rust
use sudoku_solver::{solve, Matrix};

let mut board: Matrix = [
    [5, 3, 0, 0, 7, 0, 0, 0, 0],
    [6, 0, 0, 1, 9, 5, 0, 0, 0],
    [0, 9, 8, 0, 0, 0, 0, 6, 0],
    [8, 0, 0, 0, 6, 0, 0, 0, 3],
    [4, 0, 0, 8, 0, 3, 0, 0, 1],
    [7, 0, 0, 0, 2, 0, 0, 0, 6],
    [0, 6, 0, 0, 0, 0, 2, 8, 0],
    [0, 0, 0, 4, 1, 9, 0, 0, 5],
    [0, 0, 0, 0, 8, 0, 0, 7, 9],
];

if solve(&mut board) {
    println!("{board:?}");
}
```

`1`〜`9`以外の値は`solve`内で空欄として扱います。盤面に同じ数字が初期状態から重複している場合は`false`です。探索で最初に見つかった解を返し、解の一意性は検査しません。
